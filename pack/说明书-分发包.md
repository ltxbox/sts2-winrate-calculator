# 杀戮尖塔 2 · 胜率测算（网页版）—— 使用说明

一个本地网页计算器：把卡组和遭遇填进去，它调用模拟器跑很多个种子，给你胜率和掉血区间。
**不含游戏本体**，需要你自备正版《杀戮尖塔 2》。

---

## 一、先确认三件事

1. **游戏版本**：0.114.0（或与这个版本兼容）。版本差太多模拟器会直接报错。
2. **RitsuLib**：Steam 创意工坊订阅（id 3747602295），并且已下载完。它要有 `compat\0.114.0\` 这类目录。
3. **.NET 9 运行时**：没装的话启动时会明确提示。下载：https://dotnet.microsoft.com/download/dotnet/9.0
   选 **"Run console apps"** 那一栏装（不是 SDK 也没关系）。
   （Node 不用装，包里带了。）

## 二、怎么用

1. 解压到一个**普通目录**，比如 `D:\StS2胜率测算`。
   ⚠ 别放在 `C:\Program Files` 下（那里的写入需要管理员权限，跑起来会写不了 runs/logs）。
2. 双击 **`启动.cmd`**。第一次会自动探测游戏目录、RitsuLib、.NET，然后把浏览器打开到
   `http://127.0.0.1:8766/`。
3. 左边选卡组（也可以从游戏存档导入），右边选遭遇，顶上填血量/飞升/样本数，点 **开始测算**。
4. 想看环境有没有问题，点右上角的 **自检**：真跑一局小样本，通过会显示耗时和战损。

### 三选一升级

卡组里选三张牌，每个方案都是「只把这一张升一级、其余不动」，再加上「不升级」当基线，四张卡片横着排出来比：

- 左边从当前卡组里点三张（同一行只能选一次，已经升满的行是灰的、点不动）；
- 同一批种子、同一个遭遇，所以四张卡片的胜率/战损可以直接对着看；
- 结论那行会直接说「该升 X」，平手时会写「三张升哪张都差不多」；
- 胜率一样、但掉血差得多的时候也会写出来（「胜率跟不升级一样，掉血少 16.7」）。

注意：升级是「多一张升级过的副本」——卡组里 4 张打击、已经升了 1 张，再升就是 2/4。
### 恐惧模式

顶上的 **模式** 下拉切到 **恐惧** 就能算恐惧模式：

- 恐惧只有进阶 10，所以切过去飞升会自动锁成 10（切回标准再解冻）。
- 旁边多一个 **恐惧首领** 下拉：恐惧模式里，每个首领带着一个「领域」效果（战斗开始时加灾祸、给敌人覆甲……）。
  选哪个首领，就按哪个领域去算；下拉框悬停能看到领域说明，结果区也会写「模式 恐惧 · 领域 XX」。
- 12 个恐惧首领里，**知识恶魔**暂时选不了：它的领域要在战斗开始从 2 种「灾祸」里挑 1 种，
  离线模拟没有这个选择器，硬跑会崩，所以直接把这项禁掉了。
- 恐惧模式只是改模拟规则（敌人血量/伤害、领域效果），不改变你怎么填卡组和遭遇。

### 截图导入卡组

不想一张张点卡，就在游戏里截一张图丢进来，卡组一次填好。

1. 左边「卡组」标题栏点 **截图导入**（也可以直接把图拖进对话框，或者对话框开着时 Ctrl+V 粘贴）。
2. 支持两种截图：
   - **卡组浏览页**：游戏里点开卡组看牌的那一页，每张卡有名字、费用和描述；
   - **结算页 / 跑图记录**：打完一局的结算画面，有遗物一排，卡名带 `2x` 前缀和 `+` 升级标记。
3. 等 **2–4 秒**，中间列出识别结果：每行一张卡，带卡图、名字、数量和升级勾。
4. 核对一遍，点 **应用到卡组**。

识别不准的时候：

- **标黄的行**是没把握的：下面会写「截图里是『玫击』」这种原文。不对就点 **×** 删掉，或者下拉换成对的卡。
- 如果出现**两行同名卡**（一行正常的、一行标黄的），**标黄那行默认不计入**（「计入」没打勾）——
  多半是同一个名字被读了两遍，算进去会多一张。确认是另一张，就把「计入」勾上。
- **遗物不会自动填**：遗物那排只给小图 + 下拉框，自己挑；不选就不动卡组里原来的遗物。
  因为游戏里的遗物图标带发光和描边，跟素材图对不上，自动认基本会错，所以宁可让你点。
- 角色一般能自动认（看截图里的血量上限或角色名）。显示**「未知」**就手动选一下主角色的下拉，
  否则打击/防御会按默认角色的版本填。

注意：

- 用的是 **Windows 自带的 OCR**（中文识别包）。精简版系统或没装中文语言包的机器会提示「识别失败」。
- 截图尽量**全屏、原分辨率**，别缩放、别用窗口模式截——卡越多字越小，越容易漏。
- 结算页那份卡组可能已经删过卡（比如把打击删光了），图上没有的就认不出来，这是正常的。

## 三、结果怎么看

- **胜率**：样本里赢的比例。
- **预估掉血 a–b 平均 c**：a 是最少战损的那局、b 是最多战损的那局，c 是平均。
  这个区间是**不同种子之间的波动**（起手、敌人出招不同），不是同一局里打得好/打得烂的差别。
- 下面每局一行：种子、胜负、战损、回合数、耗时。掉血最少/最多的那两局会标「最少」「最多」。

## 四、出错了怎么办

程序尽量把错误说成人话，不会只丢一串英文。常见几种：

| 看到什么 | 怎么办 |
| --- | --- |
| 没装 .NET 9 / `You must install or update .NET` | 装 .NET 9 运行时，然后重开 `启动.cmd` |
| 找不到《杀戮尖塔2》的数据目录 | 游戏没装或装在非常规位置。把 `…\Slay the Spire 2\data_sts2_windows_x86_64` 的完整路径填进 `config.json` 的 `sts2DataDir` |
| 找不到 RitsuLib / compat 目录里没有 dll | 创意工坊订阅 RitsuLib 并等它下载完；mod 版本要和游戏版本对得上 |
| 端口 8766 被占用 | 把 `config.json` 里的 `"port"` 改成 `8767`，重开 `启动.cmd` |
| 页面顶上一条红横幅 | 那里面写着具体是哪项不对、怎么修；点「重新自检」可以再查一遍 |
| 每局都显示「失败」+ 原因 | 看横幅或 `logs\server.err.log`；把红字整段发给做这个包的人 |

**日志**都在 `logs\` 里：`启动失败.txt`（启动器报错）、`server.err.log`（服务端报错）。

## 五、其他

- **停服务**：双击 `停止服务.cmd`（只停监听这个端口的 node，不动别的程序）。
- **只检查环境**：双击 `自检.cmd`，不起服务，跑一遍检查 + 一次模拟器试跑。
- **config.json**：里面五个路径留空 = 自动探测；探测失败再手填。`port` 是端口。
- 卡图是缩小过的（省体积），不影响读牌名和费用。
- 模拟器和求解器都是**打过本地补丁**的版本（支持手动改血量上限、支持恐惧模式和无头模拟）；别单独替换 `harness\` 或 `solver\` 里的文件，否则「最大血量」和「模式·恐惧」都会失效。
- 游戏或 mod 更新后，这个包可能会失效（模拟器要跟着重编）。到时候找我重新打一个。
