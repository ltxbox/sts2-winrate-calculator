# 杀戮尖塔 2 · 胜率测算（网页版）—— 使用说明

一个本地网页计算器：把卡组和遭遇填进去，它调用模拟器跑很多个种子，给你胜率和掉血区间。
**不含游戏本体**，需要你自备正版《杀戮尖塔 2》。

> **这一版（1.2.0）**：新加 **「并行」下拉**（顶部参数栏，药水右边）——同时跑几局自己调，
> 默认按你这台机器的物理核数，会记住；换个更好的电脑会自动给更多选项。
> 另外把 **Rust 求解内核** 打进了包：**弱怪**自动走 rust（同样样本快约 1.5 倍，单局搜索快 18 倍），
> 精英和 Boss 仍走原来的 C# 内核（rust 在复杂战斗上会算错，故意不用）；rust 没装好会自动退回，不影响使用。
> 1.1.4 的「战损分布 / 最好最差一局 / 导出 CSV 多 5 列」都还在。

> **1.1.4**：数据页每只怪展开后多了**战损分布**（每局掉多少血，柱状图）和
> **最好的一局 / 最差的一局**（掉血最少和最多的那两局，连着**逐回合的出牌顺序**：第 1 回合打了什么、第 2 回合…）；
> 导出 CSV 末尾也多 5 列（最好/最差一局的掉血和种子、战损分布）。注意：**旧任务没有牌序**（这项是 1.1.4 才开始记的），重跑一次就有。
> 1.1.3 的「中间只留一行 + 数据图单独网页」、终止出数据、排队自适应高度都还在；1.1.2 的单卡战损数据图按块看、密林弱怪 4 只也在。

---

## 一、先确认三件事

1. **游戏版本**：0.114.0（或与这个版本兼容）。版本差太多模拟器会直接报错。
2. **RitsuLib**：Steam 创意工坊订阅（id 3747602295），并且已下载完。它要有 `compat\0.114.0\` 这类目录。
3. **.NET 9 运行时**：没装的话启动时会明确提示。下载：https://dotnet.microsoft.com/download/dotnet/9.0
   选 **"Run console apps"** 那一栏装（不是 SDK 也没关系）。
   （Node 不用装，包里带了。）

## 二、怎么用

1. 解压到一个**普通目录**，比如 `D:\StS2胜率测算`。
   ⚠ 别放在 `C:\Program Files` 下（那里的写入需要管理员权限，跑起来会写不了 runs/logs）。
2. 双击 **`启动.cmd`**。第一次会自动探测游戏目录、RitsuLib、.NET，然后把浏览器打开到
   `http://127.0.0.1:8766/`。
3. 左边选卡组（也可以从游戏存档导入），右边选遭遇，顶上填血量/飞升/样本数，点 **开始测算**。
4. 想看环境有没有问题，点右上角的 **自检**：真跑一局小样本，通过会显示耗时和战损。

### 并行：同时跑几局（新）

顶部参数栏里 **药水** 右边有个 **并行** 下拉：

- **自动** = 按你这台机器的**物理核数**（逻辑线程数 ÷ 2）。这台 8 核 16 线程 → 自动给 8；
- 也可以手选 1–上限（上限 = 这台机器的逻辑核数，最多 64）。**选完会记住**，下次打开还在；
- 改动**从下一次点「开始测算」起生效**，正在跑的任务不受影响；
- 每个并行 = 一个常驻求解进程，也占一份内存。**机器卡、内存小就往下调**；反过来，核多、内存大就往上调。

**这台机器（i7-11800H，8 核 16 线程）的实测**，弱怪、200 局：

| 并行 | 速度 |
| --- | --- |
| 4 | 15.6 局/秒 |
| **8** | **17.3 局/秒** ← 最快 |
| 12 | 12.7 局/秒（12 个进程挤 8 个物理核，反而慢 27%） |

所以「核数越多越好」是错的：**物理核数最划算**，超过物理核数只会互相拖。

另外内存也会自动兜底：程序按「每个并行约 500MB、只用 70% 空闲内存」算一个上限，你要的数量超过它就自动压低（防止把机器跑爆）。16G 内存的机器大概能开 8 个，32G 能开 16 个。



卡组里挑要升级的牌，**数量随你**（以前是写死三张，现在 1 到 10 张都行）：每个方案都是「只把这一张升一级、其余不动」，再加上「不升级」当基线，横着排出来比：

- 左边从当前卡组里点牌，点几张就几个方案（同一行只能选一次，已经升满的行是灰的、点不动）；
- 同一批种子、同一个遭遇，所以卡片的胜率/战损可以直接对着看；
- 结论那行会直接说「该升 X」，平手时会写「这几张升哪张都差不多」；
- 胜率一样、但掉血差得多的时候也会写出来（「胜率跟不升级一样，掉血少 16.7」）。

注意：升级是「多一张升级过的副本」——卡组里 4 张打击、已经升了 1 张，再升就是 2/4。

### 升级 vs 睡觉：现在按「卡组第几行」选

同一个卡名在卡组里可能有两行（比如一行是升过的打击、一行没升）。以前下拉里按卡名选，
选一张等于「所有同名的都升」，也看不出到底升了 1 张还是全升。现在：

- 下拉里同名会分两条，标着 **（第 N 行）**，选哪条就只升那一条的 **1 张**；
- **一次就是 1 张**，所以列表里不再写「×几张」「已升几」——那几个数字以前会让人以为能选升几张；
- 已经升满的行会标 **已升满**，选不了。

### 遭遇先选地图，再选种类

遭遇面板最上面一行是**地图**：`全部 / 密林 / 暗巷 / 巢穴 / 荣耀 / 事件`，第二行才是**种类**：
`弱怪 / 普通 / 精英 / Boss / 事件`。选完地图只看这张图上的怪，四张图分别是
密林 24 只、暗巷 20 只、巢穴 21 只、荣耀 18 只（另有 8 只事件遭遇归在「事件」里）。

---

#### 每局打出：只看你选的那张牌

自选对比里选了「打击」，卡片上写的就是 **打击 每局打出 2.7 次**（比不放这张 +2.7）、每次 6.4 伤害；
全卡组的总数还留着，写在下面一行，标成「全卡组 N 张」。
多选一升级则是 **升级后 3.3 次 vs 不升级 2 次**，直接看出多打了几次。
排队表里这一列也改成「这张牌每局」，括号里是基线数字。

### 排队：多只怪连着算

以前想比十只怪，得一只一只点、一只一只等。现在 **三个模式都有自己的排队**（单场测算、自选对比、多选一升级），
右边 **遭遇** 面板下面是同一套东西：搜索 + 分类 + 怪物列表 + 排队。

- 点怪物 → 点 **+ 加入** 就进队列；**想加几只加几只**，同一只怪重复加也行（比如同一个 Boss 换三次种子前缀）；
- 点 **开始排队**，按队列顺序一只一只算，每算完一只，右下角的表格就多一行：
  - 单场测算：胜率（带 ±区间）/ 战损 / 回合 / 每局打出 / 每次伤害
  - 自选对比、多选一升级：**胜率（用这张后）** / 基线胜率 / **这次最好的那张（差几 pp）** / 战损 / 回合 / 每局打出
- 三个模式的队列各自独立、各存各的，互不干扰；
- 还没开始算的，点那一行的 **×** 就能从队列里去掉；排在前面的正在算，就先按 **■ 终止**；
- 队列存在浏览器里，关掉页面再打开还在（算完的行也留着）。

### 单卡战损预估：一次把整组怪跑完，出一张数据图

遭遇列表最上面有几行 `▣ 全部弱怪 / ▣ 全部普通怪 / ▣ 全部精英 / ▣ 全部Boss`（只在选了具体地图时出现，
「全部」和「事件」下不显示）。它们不是某一只怪，而是**这张图上那一类的全部怪**
（比如密林弱怪现在就是 4 只，飞蝇菌子那一场游戏已经删了）：

- 点一下 = 把这张图上那一类的怪**全部排进队**，和手动排 4 只怪完全一样：排队列表里就是 4 行，一只一只算；
- 可以**同时选多组**（比如密林 + 全部弱怪 + 全部普通怪），点 **开始测算** 就把它们一起排进队再跑；
- 也可以点 **+ 加入** 放进排队，再点 **开始排队**；想删就点行尾的 ×；
- 每只怪跑几场，看最上面的 **样本数**（不写死 1 场；想快就调成 1）；
- 一组全跑完，最后一行右边出现 **数据图 ↗**（同组每只都会跑到才出图），点开就是这次生成的独立 HTML。

#### 数据图怎么读：按块点进去看

打开数据图，最上面是一排**标签**：

- `默认卡组` —— 你现在的牌组，什么都不加时的表现（这就是基线）；
- `+ 打击`、`+ 防御` … —— 你在对比/升级里选的每张候选卡各一块，选了 2 张就是 2 块。

点哪个标签，下面的**整块内容只显示那一路的数据**，不会再混在一张大表里让你自己找。每块从上到下是：

1. **一行汇总**：胜率（带 ±区间）、预估掉血 a–b 平均 c、中位数、平均回合、这张牌每局打出几次；
   候选卡那块还会并排给出**基线胜率**，一眼看出「加了这张牌到底涨没涨」。
2. **横条战损图**：每只怪一条，四列对齐（怪名 / 条 / 战损 / 胜率）。
   条越长掉血越多；这一版修好了对齐问题——以前最长那条的数字会压到右边胜率上，显示成「6.00%」那种怪东西。
3. **伤害归因饼图**：这一块里伤害是谁打的、各占多少，图例带卡名。想判断「这张牌是真输出还是白拿」，看这里最快。
4. **明细表**：每只怪一行——胜率、掉血区间、平均、中位数、回合、选中那张牌每局几次。

**每只怪都能单独点开**：点它那一行（行首有个小三角），下面展开的就是**这一只怪自己的数**——
它自己的胜率、战损区间、中位数、回合、这张牌每局几次，再带一张**它自己的伤害归因饼图**。
所以「整体看还行、但某一只怪一直打不过」这种问题，展开那一行就能定位。

- 文件存在 `runs\estimates\` 下，可以直接双击打开、发给别人，也可以截图；同一组跑完会有新的，旧的不会自己删（占地方就手动清）。
- 只有整组跑才会生成数据图；平时单只怪的结果还是照旧显示在中间那栏，不落文件。

### ■ 终止

跑起来之后，右上方「自检」旁边会多出一个 **■ 终止**：

- 点它，服务端会把正在跑的模拟器子进程杀掉，剩下的样本不再派发；
- 已经算完的样本保留（进度条会显示「已终止 12/100」）；
- 没任务在跑的时候这个按钮是隐藏的。

### 自选对比（1–10 张）

想知道「往卡组里塞哪张牌更好」，用顶上的 **自选对比**：

- 左边点卡池里的牌，加进候选槽；**最多 10 张**（一开始摆 3 个空槽，加到几张就长几个槽）；
- 每张都能勾「升级态」，按升级后的版本算；
- 点 **开始对比**：基线是「不加牌」，其余每张各跑一组，同一批种子、同一个遭遇，胜率/战损横着排出来比；
- 只选 1 张也能跑（就是「加这张 vs 不加」两栏对比）。

注意：候选越多跑得越久（每张都要单独跑一整组样本），10 张的时候大约是 3 张的 3 倍时间。
### 恐惧模式

顶上的 **模式** 下拉切到 **恐惧** 就能算恐惧模式：

- 恐惧只有进阶 10，所以切过去飞升会自动锁成 10（切回标准再解冻）。
- 旁边多一个 **恐惧首领** 下拉：恐惧模式里，每个首领带着一个「领域」效果（战斗开始时加灾祸、给敌人覆甲……）。
  选哪个首领，就按哪个领域去算；下拉框悬停能看到领域说明，结果区也会写「模式 恐惧 · 领域 XX」。
- 12 个恐惧首领里，**知识恶魔**暂时选不了：它的领域要在战斗开始从 2 种「灾祸」里挑 1 种，
  离线模拟没有这个选择器，硬跑会崩，所以直接把这项禁掉了。
- 恐惧模式只是改模拟规则（敌人血量/伤害、领域效果），不改变你怎么填卡组和遭遇。

### 截图导入卡组

不想一张张点卡，就在游戏里截一张图丢进来，卡组一次填好。

1. 左边「卡组」标题栏点 **截图导入**（也可以直接把图拖进对话框，或者对话框开着时 Ctrl+V 粘贴）。
2. 支持两种截图：
   - **卡组浏览页**：游戏里点开卡组看牌的那一页，每张卡有名字、费用和描述；
   - **结算页 / 跑图记录**：打完一局的结算画面，有遗物一排，卡名带 `2x` 前缀和 `+` 升级标记。
3. 等 **2–4 秒**，中间列出识别结果：每行一张卡，带卡图、名字、数量和升级勾。
4. 核对一遍，点 **应用到卡组**。

识别不准的时候：

- **标黄的行**是没把握的：下面会写「截图里是『玫击』」这种原文。不对就点 **×** 删掉，或者下拉换成对的卡。
- 如果出现**两行同名卡**（一行正常的、一行标黄的），**标黄那行默认不计入**（「计入」没打勾）——
  多半是同一个名字被读了两遍，算进去会多一张。确认是另一张，就把「计入」勾上。
- **遗物不会自动填**：遗物那排只给小图 + 下拉框，自己挑；不选就不动卡组里原来的遗物。
  因为游戏里的遗物图标带发光和描边，跟素材图对不上，自动认基本会错，所以宁可让你点。
- 角色一般能自动认（看截图里的血量上限或角色名）。显示**「未知」**就手动选一下主角色的下拉，
  否则打击/防御会按默认角色的版本填。

注意：

- 用的是 **Windows 自带的 OCR**（中文识别包）。精简版系统或没装中文语言包的机器会提示「识别失败」。
- 截图尽量**全屏、原分辨率**，别缩放、别用窗口模式截——卡越多字越小，越容易漏。
- 结算页那份卡组可能已经删过卡（比如把打击删光了），图上没有的就认不出来，这是正常的。

### 文字导入卡组

不想一张张点，也不想截图，就直接打一行字：

```
绿护卫，白能量汲取，删一打
```

规则一句话：**默认在「初始卡组」的基础上改**（含进阶之灾），不是在你当前卡组上加。

| 写法 | 意思 |
| --- | --- |
| `绿护卫` / `护卫+` | 加一张**已升级**的护卫 |
| `白能量汲取` | 加一张**没升级**的能量汲取 |
| `2绿打击` | 加两张升级打击 |
| `删一打` / `删4防` | 删 1 张打击 / 删 4 张防御（优先删没升级的那些） |

- 卡组栏点 **文字导入**，写完先看预览：上面一行是「底子 N 张 → 改完 M 张」，中间逐条列改动（`+护卫+ ×1`、`−打击 ×1`）。
- 认不出来的短语会单列在下边（黄字），**不会**被偷偷算进去——名字得跟卡库对得上（比如「致死汲取」卡库里没有，写「能量汲取」）。
- 想接着当前卡组改，勾上「在当前卡组上改」。
- 确认无误点 **用到卡组**，弹窗自己关。

### 药水

卡组栏下面多了 **药水** 一条：

- 点 **+ 选药水**，从全部药水里搜一个名字（也可以直接翻），点一下加进卡组；
- 最多 **10 瓶**（游戏默认 3 个药水栏，有加栏遗物/模组时可以带到更多），可以重复带；
- 点药水上的 **×** 删掉。

药水会跟着测算一起算进模拟（模拟器会按最优时机喝）。

### 结算图导出

卡组栏点 **导出结算图**，直接下载一张 PNG，就是这个卡组的一览表：

- 上面：角色、飞升、血量、模式（标准/恐惧+领域）、遭遇；
- 中间：遗物（带计数的会写成「钢笔尖（攻击 9）」）、药水；
- 下面：卡牌两列，升级的写绿色 `+`，多张写 `×N`，后面跟类型和附魔。

文件名是 `卡组结算-角色-N张-日期.png`，发给朋友对卡组最省事。

### 遗物计数

有些遗物带「计数器」，比如钢笔尖（已经打出的攻击牌数）、南瓜蜡烛（点燃次数）。
它们会**直接影响战损**，所以计算器从存档里把数字一起读出来：

- 卡组栏刷新（右上角 **刷新**，或左上「从存档导入」）之后，有计数的遗物后面会出现一个**数字框**，里面就是存档里的数；
- 改完立刻生效（存在本地，下次打开还在），点「开始测算」就按这个数字打；
- 没有数字框 = 这件遗物在你存档里没有计数（或者它本来就没有）；
- 自带遗物（比如缚魂命匣）是模拟器建局时自己加的，暂时改不了它的计数。

注意：数字要写成游戏里的那个含义——「钢笔尖 攻击 9」意思是**已经打了 9 张攻击牌**，
下一次攻击就是第 10 张（双倍伤害），不是「还要再打 9 张」。

### 中间结果栏收起来（Alt+M）

中间那块「测算结果」平时是空的，占着地方。栏头右边有个 **⟨** 按钮，点一下它就收成一条窄竖条：

- 收起来以后，左边的卡组和卡池会**变宽**（卡池一行能多放好几张）；
- 开跑的时候会**自动收起**（竖条上会显示 `12/100` 这种进度），跑完**自动展开**给你看结果；
- 想手动切：点栏头的 **⟨**、点竖条、或者按 **Alt+M** 都行；
- 你自己手动收起来的话，跑完不会自己弹开（自动展开只针对「开跑时自动收的」那种）；
- 收起状态会记住，下次打开还是那个样子。

### 卡组区：多列 + 可拖的分隔线

- 中间栏收起、左栏变宽以后，卡组里的卡会**自动摊成多列**（宽屏一般 3 列），不再一张牌一行拉满整个面板；
- 卡组和下面「搜索卡牌」之间有一条线，**可以上下拖**：往上拖卡组变小、给卡池腾地方，往下拖卡组变大、看更多牌；
- 双击那条线**回到默认高度**；
- 拖过的高度会记住，下次打开还是你调的。

## 三、结果怎么看
- **胜率**：样本里赢的比例。
- **预估掉血 a–b 平均 c**：a 是最少战损的那局、b 是最多战损的那局，c 是平均。
  这个区间是**不同种子之间的波动**（起手、敌人出招不同），不是同一局里打得好/打得烂的差别。
- **中位数**：一半样本的掉血不超过这个数。极端局多的时候比平均值靠谱。
- **每局打出 X 张**：平均每局出了几张牌，用来判断这套牌「顺不顺」。
- **用药 X 瓶**：平均每局喝掉几个药水（没带药水就不显示）。
- **没打死时差 X 血**：只在有失败局时出现，平均差多少血没把敌人打死。
- 下面每局一行：种子、胜负、战损、回合数、耗时。掉血最少/最多的那两局会标「最少」「最多」。

### 数据分析（三个块）

结果区往下还有三块：

1. **伤害归因**：饼图，每张牌贡献了多少伤害、占多少比例。只统计真的打出伤害的牌，
   召唤物/毒/能力这类「不是牌直接打」的伤害算不到牌上（不会硬摊给某张牌）。
2. **打出次数**：每张牌在全部样本里一共打了几次、平均每局几次，横条长度就是次数多少。
   它和伤害归因一起看比较有用：**打出次数多但伤害低**的牌，通常是在打资源循环；
   **次数少但伤害高**的牌，就是关键输出。
3. **每回合伤害**：第 1、2、3… 回合平均打出多少伤害，能看出是「前面就打死」还是「拖到后面」。
4. **结束回合分布**：几回合打完的各有几局。平均 7 回合可能是一半 3 回合、一半 11 回合，看分布才知道稳不稳。

另外顶部还有两个容易忽略的数：

- **胜率 ±x%**：95% 置信区间（Wilson）。样本 50 局时 ± 十几很正常，别把 3 个点的差距当结论；样本越多区间越窄。
- **剩能量 x/回合**：估算值——回合开始时的能量减去这回合出牌花掉的费用。靠遗物/牌中途回的能量看不见，所以只能估。

**自选对比**里每张卡写的 **比不放 ±x.xpp**，就是「带这张牌 vs 跳过」的胜率差；一次选多张，所有卡的差距一起列出来。

顶部还有 **导出 CSV**：每局一行（种子/胜负/战损/回合/耗时），后面附掉血区间和
每张牌的打出次数，可以直接丢进 Excel 排序。

## 四、出错了怎么办

程序尽量把错误说成人话，不会只丢一串英文。常见几种：

| 看到什么 | 怎么办 |
| --- | --- |
| 没装 .NET 9 / `You must install or update .NET` | 装 .NET 9 运行时，然后重开 `启动.cmd` |
| 找不到《杀戮尖塔2》的数据目录 | 游戏没装或装在非常规位置。把 `…\Slay the Spire 2\data_sts2_windows_x86_64` 的完整路径填进 `config.json` 的 `sts2DataDir` |
| 找不到 RitsuLib / compat 目录里没有 dll | 创意工坊订阅 RitsuLib 并等它下载完；mod 版本要和游戏版本对得上 |
| 端口 8766 被占用 | 把 `config.json` 里的 `"port"` 改成 `8767`，重开 `启动.cmd` |
| 页面顶上一条红横幅 | 那里面写着具体是哪项不对、怎么修；点「重新自检」可以再查一遍 |
| 每局都显示「失败」+ 原因 | 看横幅或 `logs\server.err.log`；把红字整段发给做这个包的人 |
| 遗物后面没有计数框 | 正常：那件遗物在你存档里没有计数器。先点一次 **刷新**（从存档重读）再看 |
| 文字导入说「没认出来：XXX」 | 名字跟卡库对不上（错字/简称/别称）。换成卡库里正经的名字，或者直接在卡组里点 |
| 跑着跑着机器很卡 / 内存报警 | 把顶部 **并行** 调小（一次少跑几局），或者把其他占内存的程序关掉 |
| 弱怪算得没变快 | rust 内核没加载上会自动退回原内核（结果一样，只是慢）。看 `logs\server.err.log` 里有没有 rust-kernel 字样；多半是 `solver\rust-kernel\sts2_combat_rs.dll` 被杀毒软件删了，重新解压一份即可 |

**日志**都在 `logs\` 里：`启动失败.txt`（启动器报错）、`server.err.log`（服务端报错）。

## 五、其他

- **停服务**：双击 `停止服务.cmd`（只停监听这个端口的 node，不动别的程序）。
- **只检查环境**：双击 `自检.cmd`，不起服务，跑一遍检查 + 一次模拟器试跑。

### 数据存在哪（结果数据库）

跑过的每一批都会自动存进本机的 **结果数据库**，关掉浏览器、重启服务都还在：

- 位置：`data\sts2.db`（一个 SQLite 文件，**只有你自己这台机器有**，分发包里不带任何人的数据）；
- 存了什么：每个任务（卡组快照、遭遇、飞升、血量、灵魂/骨等参数）、每张牌的样本结果、逐回合伤害、文件夹归类、标签；
- 页面上用得着它的地方：**数据分析**、**结果对比**、**文件夹归类**、**导出 CSV**、以及任务列表里的历史记录，都从这个库读；
- `db-menu.cmd` / 数据页可以查、导出、改标签、按文件夹整理；
- **备份**：直接把整个 `data\` 目录拷走就行（`sts2.db` + 同目录 `-wal`/`-shm` 两个小文件）；
- **想清空**：先 `停止服务.cmd`，再删 `data\sts2.db*`，重启后会自动建一个空库（不会丢程序，只丢历史记录）；
- **升级不丢数据**：换新版本时把旧包的 `data\` 整个拷到新包同位置即可。

包里自带的那份库是**空库**（只有表结构），所有人的测算记录互不相通。

- 卡图是缩小过的（省体积），不影响读牌名和费用。
- 模拟器和求解器都是**打过本地补丁**的版本（支持手动改血量上限、支持恐惧模式和无头模拟）；别单独替换 `harness\` 或 `solver\` 里的文件，否则「最大血量」和「模式·恐惧」都会失效。
- `solver\rust-kernel\sts2_combat_rs.dll` 是 Rust 求解内核（弱怪走它）。它只是加速，删了程序照样能跑（自动退回 C# 内核，结果一致、速度慢些）。
- 游戏或 mod 更新后，这个包可能会失效（模拟器要跟着重编）。到时候找我重新打一个。

### 自选对比里的每张卡也带分析
